# Chess Robotic Arm

A collaborative robotic arm project designed to play chess through coordinated robotic manipulation.

## Project Overview

The project aims to design, simulate, control, and integrate robotic arms capable of interacting with a physical chess board and moving chess pieces autonomously.

## Main Areas

- Mechanical Design
- Kinematics
- Control
- Integration
- Simulation
- Firmware
